# OpenBench: MattBench

- **Source ID:** `openbench-mattbench`
- **URL:** <https://chess.n9x.co/index/>
- **Collector:** [`collectors/openbench.py`](../../collectors/openbench.py)

## How it was found

Named by the repository owner from the `#openbench-instances` channel of the OpenBench Discord (linked from the [OpenBench README](https://github.com/AndyGrant/OpenBench)). The Discord needs a login, so the URL was confirmed from public evidence below. Named "Matt".

## URL evidence

- [kelseyde/hobbes-chess-engine README](https://github.com/kelseyde/hobbes-chess-engine) and `src/tools/pretty.rs` ("MattBench https://chess.n9x.co/index/")

## Notes

- Restyled UI with a collapsible engine directory.
- `https://openbench.nocturn9x.space/` serves the same MattBench instance and is not registered separately.
- Its Torch entry links ChessCom/TorchDev, a private repository (HTTP 404), so Torch gets no source link.
- Its Fairy-Stockfish entry links the Silverrzz fork, credited to fairy-stockfish/Fairy-Stockfish.
